# 📖 RevCraft 파일 버전 관리 프로그램 사용설명서

**RevCraft**는 파일 데이터 손상 없이 파일 끝(Trailer)에 버전을 관리하는 메타데이터를 추가하여, 파일의 변경 이력 및 이전 버전의 위치/삭제 상태를 추적할 수 있도록 도와주는 프로그램입니다.

---

## 💡 주요 특징

1. **자동 파일명 생성 규칙**: 오늘 날짜와 버전 번호를 조합하여 파일명을 자동으로 생성합니다.
* **예시**: `★2026.09.28 파일명v1.ext` $\rightarrow$ `★2026.09.28 파일명v2.ext`


2. **트레일러(Trailer) 기반 버전 이력 저장**: 원본 파일 내용을 변경하지 않고, 파일 끝에 JSON 메타데이터를 16진수(Hex) 형태로 안전하게 덧붙입니다.
3. **스마트 파일 추적**: 이전 버전 파일이 다른 폴더로 이동하거나 삭제되어도 고유 식별자(GUID) 및 파일명을 탐색하여 현재 상태를 자동으로 감지합니다.
4. **구버전 호환성 지원**: 단순 경로 문자열로 저장되던 이전 버전 메타데이터 방식과의 호환성을 유지합니다.

---

## 🛠 주요 기능 및 사용법

### 1. 파일 검사 및 이력 조회 (`InspectFile`)

파일의 존재 여부, 크기, 수정일 및 해당 파일에 연결된 **이전 버전 체인 목록**을 확인합니다.

* **동작 내용**:
* 파일 끝의 메타데이터를 읽어 연결된 이전 버전들의 이력을 불러옵니다.
* 이전 버전 파일들의 현재 상태를 확인하여 상태 정보를 최신화합니다.


* **상태 표시 아이콘**:
* `✔ 정상`: 원본 위치에 파일이 존재함 (`Active`)
* `🔄 위치 이동됨`: 파일이 다른 디렉토리로 이동됨 (`Moved`)
* `✖ 삭제됨`: 파일을 찾을 수 없음 (`Deleted`)



---

### 2. 새 버전 생성 및 백업 (`ProcessFile`)

원본 파일을 복사하여 새 버전의 백업 파일을 만들고, 버전 관리 정보를 업데이트합니다.

* **처리 과정**:
1. 원본 파일명을 분석하여 다음 버전 번호(v1 $\rightarrow$ v2)와 저장 경로를 결정합니다.
2. 직전 부모 파일 정보와 기존 버전 이력을 수집하고, StepIndex를 1씩 증가시켜 체인을 연결합니다.
3. 이동되었거나 삭제된 이전 버전들의 상태를 자동으로 감지 및 갱신합니다.
4. 생성된 버전 이력을 JSON으로 직렬화한 뒤 16진수로 변환하여 복사된 대상 파일 끝에 덧붙입니다.



---

### 3. 이동된 파일 스마트 탐색 (`LocateMovedFile`)

이전 버전 파일이 원래 위치에 없을 경우, 다음 위치들을 우선적으로 자동 탐색합니다.

1. **현재 파일 폴더 및 상위(부모) 폴더**
2. **원본 파일 폴더 및 상위/형제 폴더**
3. **주요 사용자 폴더** (바탕화면, 문서 등)

* *최대 1,500개의 파일까지 탐색하여 GUID 검증을 통해 이동된 위치를 찾아냅니다.*
